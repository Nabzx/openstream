what

OpenStream is a free, open-source take on Wispr Flow that runs entirely on your Mac. A local model (Parakeet, on the Neural Engine) transcribes your speech on the machine, so nothing you say is sent anywhere, and there is no account to make.

It also has one rule worth knowing. A spoken "new paragraph" only becomes a real line break in apps where a line break is safe. In a terminal or a chat box a stray newline can fire off something half-finished, so there the words just carry on.

install
# apple silicon, macOS 14+, node 22.12+, xcode CLT
$ git clone https://github.com/Nabzx/openstream.git
$ cd openstream && npm install && npm start

The transcription model downloads on first launch, about 470 MB. npm run doctor checks the permissions.

status

  • No account, no cloud, no telemetry, and that won't change.
