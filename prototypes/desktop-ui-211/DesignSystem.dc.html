Window chrome & vibrancy

Chrome: titleBarStyle: 'hiddenInset' — traffic lights inset top-left, content runs full height. Default 760×580, min 560×440, resizable, size + position persisted.
Vibrancy: the 52px toolbar strip uses macOS vibrancy (under-window); content surfaces are solid. The push-to-talk overlay keeps its own hud vibrancy — shared tokens (accent, radii, SF), separate material.
Tray: unchanged — stays the live idle / recording / transcribing indicator; the window never carries in-dictation state.
